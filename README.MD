## 🤝 Colaboración al repositorio
 
Si deseas contribuir a este proyecto, sigue estos pasos:
 
1. Haz un **fork** del repositorio.
2. Crea una rama para tu funcionalidad o corrección:
```bash
   git checkout -b feature/nombre-de-la-funcionalidad
```
3. Realiza tus cambios y haz commit siguiendo un mensaje claro:
```bash
   git commit -m "feat: descripción breve del cambio"
```
4. Haz push a tu rama:
```bash
   git push origin feature/nombre-de-la-funcionalidad
```
5. Abre un **Pull Request** describiendo los cambios realizados.
**Buenas prácticas:**
- Sigue la convención de nombres y estilo de código ya existente en el proyecto.
- Verifica que las pruebas (si existen) pasen antes de enviar el PR.
- Documenta cualquier función o módulo nuevo.
